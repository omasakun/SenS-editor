== キーと機能の関係 ==
↑: より広い範囲の譜面を表示
↓: より狭い範囲の譜面を表示
左: 音楽を100ms遡る
→: 音楽を100ms進める
[ : 音楽の再生スピードを速く
] : 音楽の再生スピードを遅く
Enter: BPM線に合わせるかどうかを変更
Space: 音楽の再生、一時停止
Esc: 曲の終わりを意味するノーツを追加
QWER: DFJKLのキーで、
 - Q: ノーツ削除
 - W: ノーマルノーツ追加
 - E: チェーンノーツ追加
 - R: ほるどノーツ追加
 を行うようなモードにする。

== 譜面制作者のための関数 ==
以下の関数が用意されています。Consoleに入力してお使いください。

editNotes(fn: (notes: NoteData[]) => NoteData[])
  ノーツのリストを編集する関数を渡すと、その通りにノーツを編集します。
  ~使用例~
  editnotes(notes => []]) // すべてのノーツを削除します
  editnotes(notes => notes.filter(note => note.type=="end" || note.lane<=4)) // 1~4レーン目にないノーツを削除

editNote(fn: (notes: NoteData[]) => NoteData)
  ノーツを編集する関数を渡すと、その通りにノーツを編集します。
  ~使用例~
  editnote(note => {note.lane=0;return note}) // すべてのノーツを1レーン目に移動

editNoteTime(fn: (time: number) => number)
  ノーツの時間を編集する関数を渡すと、その通りに編集してくれます。
  ~使用例~
  editNoteTime(time=>time-1000) // すべてのノーツの時間を1000ミリ秒前にする
  editNoteTime(time=>0) // すべてのノーツの時間を0にする
